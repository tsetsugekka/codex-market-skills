# 公共与私密 Reference 双读契约

每次使用本 Skill，先按当前问题读取相关的公共 `references/` 段落及必要约束，再检查本机已获授权的私密索引，读取其中映射到本 Skill、且适用于本次任务的私密 reference。两层均适用时必须都读，不能因私密资料存在而跳过公共方法，也不能用公共资料代替可用的私密修订。只读相关段落；本轮已读的 Skill 或 reference 不重复加载，跨 Skill 引用不递归展开整套资料。文件缺失、无权限或环境无法访问时如实说明，继续使用可验证的公共资料，不声称读过私密内容。

私密索引由用户或项目明确提供；文件系统可用时，也检查 `${CODEX_HOME}/market-skills/private-references.md`，未设置 `CODEX_HOME` 时检查 `~/.codex/market-skills/private-references.md`。索引置于仓库外，按 Skill 标明私密 reference、适用范围，以及每项私密修订对应的公共段落、修订理由和日期。没有可读索引时停止私密资料查找，不扫描其他目录或猜测文件名。索引只负责定位资料，不自动授权读取其他账户、真实持仓、交易，也不授权发信或写入外部服务；仍须遵守当前任务权限。

结合两层解释时，核对来源、时效、证据与适用条件。有依据的公共或私密方法修订可用于相应范围；本地采用私密修订时注明这一点，但不泄露私密原文或路径。无证据的冲突应列为未解决，不拼成确定结论；任何修订均不能覆盖真实性、权限或安全边界。私密文件及索引不进入 GitHub、插件包，也不得作为第三方工具的载荷上传。只有用户明确要求更新公开 Skill 且内容经独立脱敏审查后，才可写入公开经验；不能因本地研究自动回写。
